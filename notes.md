# Notes / Notas

## English
- Start strict; relax only with a documented reason.
- Prefer `NodeNext` for modern Node packages.
- Enable `noUncheckedIndexedAccess` to catch empty-index bugs early.

## Português
- Comece strict; relaxe só com razão documentada.
- Prefira `NodeNext` para packages Node modernos.
- Ative `noUncheckedIndexedAccess` para apanhar bugs de índice cedo.
